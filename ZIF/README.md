# ZIF_001 – Exemplos de Condicionais em ABAP

Este arquivo contém um conjunto de exemplos práticos de estruturas condicionais em ABAP, desenvolvidos para fins de estudo no curso SAP ABAP (Udemy).  
O programa **ZIF_001** demonstra diferentes formas de utilizar `IF`, `ELSEIF`, `ELSE`, operadores lógicos e verificações de valores iniciais.

## 📌 Objetivo do Código
O propósito deste programa é apresentar, de forma simples e didática, como funcionam as principais estruturas de decisão no ABAP, incluindo:

- IF simples  
- IF com ELSE  
- IF com ELSEIF  
- Condicionais com operadores lógicos (`AND`, `OR`)  
- Uso de valores booleanos (`abap_true`, `abap_false`)  
- Verificação de campos iniciais (`IS INITIAL`, `IS NOT INITIAL`)

## 🧩 Conteúdo Demonstrado

### ✔️ IF simples
Verifica se um número é igual a um valor específico.

### ✔️ IF com ELSE
Classifica idade como maior ou menor de idade.

### ✔️ IF com ELSEIF
Avalia notas e retorna mensagens como “Excelente”, “Aprovado”, “Precisa estudar” ou “Reprovado”.

### ✔️ Operadores lógicos
Compara altura usando condições combinadas com `AND`.

### ✔️ Condicional com booleanos
Verifica se a pessoa tem idade mínima e CNH válida para dirigir.

### ✔️ Condicional com OR
Permite processar quando o status é “liberado” ou “Ativo”.

### ✔️ Verificação de valor inicial
Testa se o material foi informado ou não usando `IS INITIAL` e `IS NOT INITIAL`.

## 📁 Estrutura do Arquivo
- **ZIF_001.abap** – Código-fonte contendo todos os exemplos comentados.

## 🎯 Utilidade
Este programa serve como referência rápida para iniciantes em ABAP que desejam entender e praticar estruturas condicionais de forma clara e organizada.

# ZIF_001 – ABAP Conditional Examples

This file contains practical examples of conditional structures in ABAP, created for study purposes in the SAP ABAP Udemy course.  
The **ZIF_001** program demonstrates different ways to use `IF`, `ELSEIF`, `ELSE`, logical operators, and initial value checks.

## 📌 Purpose of the Code
The goal of this program is to show, in a simple and educational way, how ABAP decision structures work, including:

- Simple IF  
- IF with ELSE  
- IF with ELSEIF  
- Logical operators (`AND`, `OR`)  
- Boolean values (`abap_true`, `abap_false`)  
- Initial value checks (`IS INITIAL`, `IS NOT INITIAL`)

## 🧩 Demonstrated Concepts

### ✔️ Simple IF
Checks whether a number matches a specific value.

### ✔️ IF with ELSE
Classifies a person as an adult or minor.

### ✔️ IF with ELSEIF
Evaluates grades and prints messages such as “Excellent”, “Approved”, “Needs study”, or “Failed”.

### ✔️ Logical operators
Compares height using combined conditions with `AND`.

### ✔️ Boolean conditions
Checks if a person meets age and license requirements to drive.

### ✔️ OR condition
Allows processing when status is “liberado” or “Ativo”.

### ✔️ Initial value check
Tests whether a material number was provided using `IS INITIAL` and `IS NOT INITIAL`.

## 📁 File Structure
- **ZIF_001.abap** – Source code containing all commented examples.

## 🎯 Usefulness
This program serves as a quick reference for ABAP beginners who want to understand and practice conditional structures clearly and effectively.
