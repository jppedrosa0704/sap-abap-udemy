# 📦 SAP Material Master – Tabelas Principais (PT + EN)

Este repositório contém um ficheiro `.abap` com a lista das principais tabelas do **Material Master (SAP MM)**, em **Português e Inglês**, organizado para consulta rápida por estudantes, consultores e desenvolvedores ABAP.

---

## 🧑‍💻 Sobre o Projeto

Este repositório foi criado para documentar e estudar as tabelas mais importantes relacionadas ao **Material Master** no SAP ERP / S/4HANA.  
Inclui:

- Lista completa das tabelas MARA, MARC, MARD, MBEW, etc.  
- Versão bilingue (PT + EN)  
- Estrutura organizada em formato `.abap`  
- Comentários claros e padronizados  
- Material útil para quem está a aprender SAP MM ou ABAP

---
