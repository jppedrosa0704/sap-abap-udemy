# ZABAP_101 – Operadores Aritméticos em ABAP

Este programa demonstra o uso dos principais operadores aritméticos disponíveis na linguagem ABAP.  
O objetivo é apresentar, de forma simples e prática, como realizar operações matemáticas básicas e avançadas utilizando variáveis do tipo `p` (packed number).

## 📌 Objetivo do Código
O programa **ZABAP_101** mostra exemplos de:

- Adição (`+`)
- Subtração (`-`)
- Multiplicação (`*`)
- Divisão (`/`)
- Potência (`**`)
- Resto da divisão (`MOD`)
- Divisão inteira (`DIV`)

Cada operação é executada e exibida no console usando o comando `WRITE`.

## 🧩 Variáveis Utilizadas
- **a** – valor inicial 10  
- **b** – valor inicial 3  
- **resultado** – variável usada para armazenar o resultado de cada operação

Todas as variáveis são do tipo `p` com duas casas decimais.

## 🧮 Operações Demonstradas

### ➕ Adição
`resultado = a + b.`

### ➖ Subtração
`resultado = a - b.`

### ✖️ Multiplicação
`resultado = a * b.`

### ➗ Divisão
`resultado = a / b.`

### 🔼 Potência
`resultado = a ** b.`  
Eleva o valor de **a** à potência **b**.

### 🔢 Resto da divisão
`resultado = a MOD b.`  
Retorna o resto da divisão inteira.

### 🧱 Divisão inteira
`resultado = a DIV b.`  
Retorna apenas a parte inteira da divisão.

## 🎯 Utilidade
Este programa serve como referência para iniciantes que desejam aprender e praticar operações matemáticas em ABAP de forma clara e objetiva.

# ZABAP_101 – Arithmetic Operators in ABAP

This program demonstrates the use of the main arithmetic operators available in ABAP.  
The goal is to show, in a simple and practical way, how to perform basic and advanced mathematical operations using `p` (packed number) variables.

## 📌 Purpose of the Code
The **ZABAP_101** program includes examples of:

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Power (`**`)
- Modulo (`MOD`)
- Integer division (`DIV`)

Each operation is executed and printed using the `WRITE` statement.

## 🧩 Variables Used
- **a** – initial value 10  
- **b** – initial value 3  
- **resultado** – variable used to store each operation result

All variables are type `p` with two decimal places.

## 🧮 Demonstrated Operations

### ➕ Addition
`resultado = a + b.`

### ➖ Subtraction
`resultado = a - b.`

### ✖️ Multiplication
`resultado = a * b.`

### ➗ Division
`resultado = a / b.`

### 🔼 Power
`resultado = a ** b.`  
Raises **a** to the power of **b**.

### 🔢 Modulo
`resultado = a MOD b.`  
Returns the remainder of the division.

### 🧱 Integer Division
`resultado = a DIV b.`  
Returns only the integer part of the division.

## 🎯 Usefulness
This program serves as a quick reference for beginners learning how to perform arithmetic operations in ABAP.
